# Aurora CPF Cleaner

Extensão Chrome Manifest V3 que oculta automaticamente elementos com a classe `.aluno-cpf` nas páginas visitadas.

## Instalação (ZIP)
1. Baixe o ZIP em **Actions → Build extension → Artifacts**.
2. Extraia o arquivo.
3. Abra `chrome://extensions`.
4. Ative **Modo do desenvolvedor** e clique em **Carregar sem compactação**.
5. Selecione a pasta extraída.

## Configuração
Clique no ícone da extensão para ativar ou desativar a ocultação.

## CRX
O workflow também prepara um pacote CRX3 quando uma chave privada de assinatura é configurada no segredo `CRX_PRIVATE_KEY` do repositório. Nunca publique essa chave.
